# Welcome to Retro Folks!
Retro Folks is a project where the game "Retro Slap Battles" on Retrostudio (Roblox), is a Friday Night Funkin' mod!
## How do I download this mod?
- Your [Psych Engine](https://github.com/ShadowMario/FNF-PsychEngine/releases) MUST be v1.0.3 (if others work good enough, I guess.)
- Download the "RetroFolks" folder (I guess the entire project) and put it in your mods folder. (\PsychEngine\mods\RetroFolks for example)
- If everything works, the mod "Retro Folks" should be in your Psych Engine mods list! Enable it, and you can play my mod!
## What is Retro Slap Battles?
Retro Slap Battles (Formerly Retro Battles) is a Retrostudio game on Roblox, that is a recreation of the original Slap Battles but "retro" (Just in a 2015 recreation). It is currently growing and isn't as greedy as the original Slap Battles.
## Why did I make this?
I met most of my online friends in this game, so I thought of making an FNF mod since the game was pretty small and didn't have much replayability.
